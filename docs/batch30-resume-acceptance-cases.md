# 第 30 批：学习能力简历验收用例

- [ ] 当前简历：有方向、有阶段作答证据时，随时可生成；只列有证据支撑的能力，不把任务完成或打卡当成掌握证据。
- [ ] 无证据阶段：即使该阶段的任务已全部完成，也不出现在「已验证」能力中，且不显示为掌握度 0%。
- [ ] 门槛以下：阶段有作答证据，但掌握度低于总规划最终裁定的认证门槛时，不标为「已验证」。
- [ ] 门槛边界：阶段掌握度恰好等于总规划最终裁定的认证门槛时，归档结果与获批的边界规则一致。
- [ ] 状态分档：同一输入中的「已验证」「已学习未验证」「待获得」互不冒充；无证据项不使用「掌握」措辞。
- [ ] 证据出处：每条展示的能力均标明对应阶段、作答证据条数和掌握度百分比；无证据时不编造百分比。
- [ ] 目标简历：设定学习目标后立即可生成；方向技能差距中的技能标为「待获得」，不写成现有能力。
- [ ] 结业版：全部任务完成后展示的结果与同一时刻的当前简历一致；完成任务本身不增加「已验证」能力。
- [ ] 个人资料缺省：用户未填写学校、实习、项目、获奖、手机号或邮箱时，输出不含这些字段和值。
- [ ] 个人资料自填：用户填写的学校、实习、项目、获奖和联系方式只显示用户填写的内容，不生成额外经历或联系方式。
- [ ] 敏感字段：输出与浏览器打印结果不包含账号密码。
- [ ] 数字保真：模型润色前后，阶段、作答证据条数、掌握度百分比等数字字段逐项相等；润色不得补造事实。
- [ ] 用户隔离：甲用户的简历及打印结果不包含乙用户的阶段、作答证据或自填信息。
- [ ] 打印为 PDF：预览页通过浏览器打印可生成可读结果，三档状态、证据出处及已填字段与预览一致。
- [ ] 数据结构：第 30 批验收前后数据库表与迁移版本不变，前端依赖清单不增加新项。
