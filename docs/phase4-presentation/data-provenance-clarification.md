# 学习数据来源与答辩口径

本说明记录 2026-11-02 数据真实性审计的证据边界，数据是当时的只读查询结果，后续账户状态可能变化。

## 工程巡检与真实学习

`super` 账户用于工程演示和流程巡检。审计时最新规划标题含“自动巡检”，最近四条打卡备注为“自动用户流程巡检”。这些记录可用于复现和核对产品流程，不能把它们当作真实学生的学习投入、知识掌握或学习成效。账户中可能同时存在其他来源的记录；仅凭账户名不能判定每一条记录的来源。

隔离环境中上传资料、练习、判分、补强及重测的工程验收，可说明被验证的流程在当次条件下能够运行；它不能证明系统对真实学生有效。模型判分理由和引用仍需要人工核查相关性。

## 尚未完成的验证

当前没有完成独立人工判分对照、真实学生试用或有对照的前后测。第三阶段已有的表格、试用指南和问卷仅是材料框架，不能作为这些验证已完成的证据。因此不得声称已验证的判分准确率、补强有效率、学习提升比例或“真实性从 60% 提升到 85%+”。

技术文档中历史 67% 是一次工程验收断面的三条作答事件（两条正确、一条错误）按现有规则计算的得分，包含重复作答；它不是补强有效率、真实学生通过率或学习效果。展示时宜直接说明“已完成工程流程验收”，不要将该数字当作效果证明。

## 建议答辩表述

“我们使用巡检样本验证了学习记录、判分回看、补强确认与重测的工程链路。判分引用可供核对，但字面匹配不能证明资料在语义上支持结论。真实学生试用和独立判分对照尚待完成，当前不能给出学习效果比例。”
