# StudyPilot 轻量自然女声

已停止 Qwen3-TTS 本地大模型方案，清理大模型、CUDA/PyTorch 安装环境和下载缓存。

目前保留的是微软晓晓在线自然女声的轻量客户端，以及已生成的固定问候音频
`output/greeting-xiaoxiao.mp3`。免 API Key，不需要 GPU 或下载模型。

## 项目内文件

- `.venv-edge/`：仅包含 edge-tts 及必要依赖的独立运行环境。
- `output/greeting-xiaoxiao.mp3`：已实际合成的固定问候音频。
- `requirements.txt`、`setup.ps1`：重建轻量环境；安装与缓存仍限定在本目录。

## 在线语音说明

固定问候可以直接播放本地音频，不发送聊天内容。
用户已明确同意：仅将点击朗读的回复文字发给微软在线语音服务。
回复按句分段合成，当前段播放时预取同一条回复的下一段。其他消息、聊天历史和资料不随请求发送。
点击停止会取消后续请求；已经发出的当前合成请求可能继续至超时，但不会继续播放。
无需额外启动语音服务，照常启动 StudyPilot 即可。
不回退到此前用户反馈不自然的系统合成音色。

客户端来源：https://github.com/rany2/edge-tts 。在线服务的可用性依赖网络和上游服务。
