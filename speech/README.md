# StudyPilot 轻量自然女声

已停止 Qwen3-TTS 本地大模型方案，清理大模型、CUDA/PyTorch 安装环境和下载缓存。

目前保留的是微软晓晓在线自然女声的轻量客户端，以及已生成的固定问候音频
`output/greeting-xiaoxiao.mp3`。免 API Key，不需要 GPU 或下载模型。

## 项目内文件

- `.venv-edge/`：仅包含 edge-tts 及必要依赖的独立运行环境。
- `output/greeting-xiaoxiao.mp3`：已实际合成的固定问候音频。
- `requirements.txt`、`setup.ps1`：重建轻量环境；安装与缓存仍限定在本目录。

## 在线语音说明

固定问候可以直接播放本地音频，不发送聊天内容。
用户已明确同意：新回复完整生成后，自动将该条正文发给微软预生成语音；不自动播放。
历史回复不会因打开面板而批量上传，用户点击朗读历史正文时才生成未缓存音频。
回复正文按句分段，通过短期、带登录校验的播放地址流式返回 MP3，收到音频即开始播放，不必等整段生成完成。
播放地址不包含正文；其他消息、聊天历史和资料不随请求发送。下一段只预先创建播放凭证。
已经完整生成的音频按用户隔离缓存在后端内存中，保留15分钟、总计最多16MiB/128段；不落盘。
重复点击以及在主聊天和小聊天框之间切换，可复用缓存，省去再次联网生成。
点击停止会取消后续请求并断开音频流；后端会终止当前语音子进程并释放并发槽。
无需额外启动语音服务，照常启动 StudyPilot 即可。
不回退到此前用户反馈不自然的系统合成音色。

客户端来源：https://github.com/rany2/edge-tts 。在线服务的可用性依赖网络和上游服务。
缓存播放可快速开始；未缓存内容的首次播放仍需要网络握手和上游生成，无法保证每次低于1秒。
新回复预生成完成后，首次点击也直接使用缓存；若刚生成正文就点击、预生成还未完成，则等待已有任务，避免重复合成。
